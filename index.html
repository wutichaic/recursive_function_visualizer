Definitions used by this tool

    
Composition. For g : ℕ0k → ℕ0 and hi : ℕ0m → ℕ0, f = g ∘ (h1, …, hk) is f(x̄) = g(h1(x̄), …, hk(x̄)). It is defined only where every hi(x̄) is defined and g is defined at those values.

    
Primitive recursion runs on the last argument. For g : ℕ0m → ℕ0 and h : ℕ0m+2 → ℕ0, f = ρ(g, h) is f(x̄, 0) = g(x̄) and f(x̄, n + 1) = h(x̄, n, f(x̄, n)). When m = 0, g is a constant C0c.

    
Minimization. For g : ℕ0m+1 → ℕ0, f = μ(g) has f(x̄) = z when g(x̄, z) = 0 and, for every k < z, g(x̄, k) is defined and nonzero. If there is no such z, f(x̄) is undefined (written ⊥). The tool evaluates g(x̄, 0), g(x̄, 1), … in order, which is exactly this rule.


    
Names for the classes

    
The primitive recursive functions are built from the initial functions with composition and primitive recursion; they are all total. Adding minimization gives the partial recursive (μ-recursive) functions, which may be undefined at some inputs. A partial recursive function that is defined at every input is a recursive (total recursive) function. So every primitive recursive function is recursive, and every recursive function is partial recursive.

    
The tool labels a definition by how it was built: “primitive recursive” if no μ is used anywhere in it, otherwise “partial recursive (uses μ)”. A function built with μ can still be total, or even primitive recursive by a different construction; the value table shows where it was defined on the inputs tried.


    
Ackermann’s function

    
A(0, n2) = n2 + 1,   A(n1 + 1, 0) = A(n1, 1),   A(n1 + 1, n2 + 1) = A(n1, A(n1 + 1, n2))

    
In closed form, A(n1, n2) = 2 ↑n1−2 (n2 + 3) − 3, reading 2 ↑−1 x = 2 + x and 2 ↑0 x = 2x. For example A(1, n) = n + 2, A(2, n) = 2n + 3, A(3, n) = 2n+3 − 3. It is recursive but not primitive recursive.


    
About “no value within the step limit”

    
Each application of S, C or P, each composition, each recursion step and each μ trial counts as one step. When a μ search reaches the step limit without finding a zero, the tool can’t tell whether a zero comes later or never comes; it shows the input as having no value so far. Raise the step limit to search further.
